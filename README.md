# Modern Beacon GUI

## Features

* Resize GUI: Make the size of beacon GUI as big as other container GUIs.
* Quick Move: Add quick move for the payment slot.
* Icon cycling: Add a cycling background for the payment slot.

## Important Notes

* If only installed in the server, the client will have visual flickering.
* If only installed in the client, the quick move will be disabled.

## Dependencies

* Fabric API: required
* Cloth Config API: optional
* Mod Menu: optional
